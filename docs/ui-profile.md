# ملف واجهة Aspir (ملحق دليل مراجعة البطاقات)

## المنتج والمستخدمون
- Aspir (اسبير): نقطة بيع لمحلات قطع الغيار في السودان.
- المستخدمون: الكاشير (سرعة، لمس)، المدير (متابعة وقرارات)، زوار المتجر العام `/store` و`/shop`.
- المنصات: سطح مكتب + هاتف باللمس + PWA. أجهزة أندرويد ضعيفة، وقد يعمل بشبكة محلية أو دون اتصال.
- العروض المدعومة: 360–1920px (نقاط التحول md=768، lg=1024).

## اللغة والخط
- العربية RTL فقط. استخدم الخصائص المنطقية (`ms-*`, `ps-*`, `border-s`…).
- الخط Tajawal (400/500/700/800/900).
- الأرقام والمبالغ بالأرقام الهندية `toLocaleString('ar-SA')`؛ الأكواد (رقم القطعة، الباركود، الهاتف) لاتينية. (افتراض يحتاج تأكيد المالك)

## الثيم
- لوحة الإدارة داكنة (surface-950 `#0C141F`، surface-800 `#131E2D`، surface-700 `#2A3A4C`، primary `#159AA4`/`#0E7C86`).
- المتجر العام فاتح. لا مبدّل ثيم.

## المكدّس والمكوّنات المشتركة
React 19 / Vite 8 / Tailwind 4 / lucide.
المشترك: ModalShell, Pagination, PaymentMethodBadge, BrandMark, ScrollTable, FileInput, cash/StatCard, PageStates, `.glass-card` (سطح صلب، ليس زجاجياً).

## كلمات الهوية
هادئ، دقيق، موثوق، سريع القراءة.

## الاتجاه المختار
**A (الهادئ الدقيق) + قائمة «ما يحتاج تدخلك الآن» من C** — مطبّق على لوحة التحكم. الباقي: ترحيل بقية الشاشات تدريجياً (`npm run lint:ui` يعرض المتبقي). المبالغ الصحيحة بلا «٫٠٠».

## شاشات تمثيلية
لوحة التحكم، نقطة البيع، قطع الغيار (تحديد/فارغ)، الطلبات، الإغلاق اليومي، العملاء (جوال)، المتجر.

## استثناءات من الفحص (`ui-allow:`)
نبض الهيكل العظمي أثناء التحميل، مؤشر عنصر التنقل النشط، حلقات التركيز.

## الأوامر
- `npm run lint:ui` — فحص الأنماط الممنوعة (تصاعدي مقابل `scripts/ui-lint-baseline.json`).
- `npm run shots` — لقطات الشاشات إلى `frontend/shots/<label>/`.
