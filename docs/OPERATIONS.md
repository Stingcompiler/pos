# اسبير — دليل التشغيل داخل المحل

هذا الدليل لصاحب المحل ومن يجهّز النظام له. يغطي: تشغيل النظام داخل المحل
بلا إنترنت، النسخ الاحتياطي والاستعادة، إدخال الأصناف من Excel، والعمل
اليومي (البيع، الآجل، المرتجعات، إقفال اليومية، مطابقة التحويلات، الجرد،
التسعير بسعر الصرف).

---

## 1. التشغيل داخل المحل (الوضع المحلي)

النظام يعمل على جهاز واحد داخل المحل (لابتوب أو جهاز مكتبي صغير)، وتفتحه
أجهزة المحل الأخرى (هواتف، تابلت، جهاز الكاشير) عبر شبكة الواي فاي نفسها.
البيع يستمر عند انقطاع الإنترنت، لأن الأجهزة تتصل بالجهاز المحلي لا بالإنترنت.

**مهم:** الجهاز الرئيسي يحتاج كهرباء مستقرة. يُنصح بـ UPS أو بطارية/طاقة
شمسية للجهاز والراوتر معاً.

### التجهيز لأول مرة

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate            # على لينكس/ماك: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env             # على لينكس/ماك: cp .env.example .env
```

اضبط في `backend/.env`:

```
DJANGO_DEBUG=False
DJANGO_LOCAL_NETWORK=True
DJANGO_BACKUP_DIR=D:\Google Drive\pos-backups
```

ثم:

```bash
cd ../frontend && npm ci && npm run build
cd ../backend
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py createsuperuser
python manage.py seed_vehicles      # اختياري: موديلات السيارات الشائعة
```

### التشغيل اليومي

```bash
python manage.py serve_local
```

يطبع الأمر عناوين مثل `http://192.168.1.10:8000`؛ افتحها من أي جهاز على
شبكة المحل. يمكن إضافة الأمر لبدء تشغيل ويندوز (Task Scheduler) حتى يعمل
تلقائياً عند تشغيل الجهاز.

> الوضع المحلي بلا HTTPS، فهو للشبكة الداخلية فقط. لا تفتح المنفذ 8000 على
> الإنترنت. للنشر على الإنترنت استخدم الإعدادات الافتراضية مع HTTPS.

## 2. النسخ الاحتياطي والاستعادة

`serve_local` ينشئ نسخة عند التشغيل ثم كل 24 ساعة (يمكن تغييرها:
`--backup-hours 6`). ويمكن النسخ يدوياً في أي وقت:

```bash
python manage.py backup_data
```

- النسخة ملف واحد: البيانات كلها (ومعها قائمة جلسات الدخول المُلغاة، فلا تعود
  صالحة بعد الاستعادة) + صور القطع والإشعارات + بيان تحقق.
- النسخ أثناء البيع آمن: البيانات تُقرأ من لقطة واحدة للحظة بدء النسخ، والبيع
  يستمر بلا انتظار.
- **لا تنسخ ملف `db.sqlite3` يدوياً** والنظام يعمل: القاعدة في وضع WAL، وآخر
  العمليات تكون في ملف `db.sqlite3-wal` المجاور. استخدم `backup_data` دائماً.
- تُحفظ في `DJANGO_BACKUP_DIR`. **اجعله خارج الجهاز فعلياً**: مجلد متزامن
  مع Google Drive أو Dropbox، أو قرص خارجي يُفصل ويُحفظ في مكان آخر.
- يُحتفظ بآخر 14 نسخة (`DJANGO_BACKUP_KEEP`).

### التشفير (موصى به عند الرفع إلى السحابة)

```bash
python manage.py backup_data --generate-key
```

ضع الناتج في `DJANGO_BACKUP_KEY` داخل `.env`، **واحفظه في مكان آمن منفصل**
(ورقة مطبوعة في خزنة مثلاً). بدون المفتاح لا يمكن استعادة النسخ المشفّرة.

### الاستعادة (جهاز جديد أو بعد عطل)

```bash
python manage.py migrate
python manage.py restore_data "D:\Google Drive\pos-backups\backup-20261007-230000.zip"
```

الأمر يتحقق من سلامة الملف قبل أي كتابة، ويرفض الاستعادة فوق قاعدة فيها
بيانات إلا مع `--force` (يمسحها أولاً)، ثم يطابق أعداد السجلات مع النسخة. إن
لم تطابق يُلغى كل شيء، ويشمل ذلك المسح، فتبقى القاعدة كما كانت.

**جرّب الاستعادة مرة كل شهر على جهاز آخر**؛ النسخة التي لم تُجرّب استعادتها
لا يُعتمد عليها.

## 3. إدخال الأصناف من Excel

من صفحة **قطع الغيار** ← «تحميل القالب»، املأه، ثم «استيراد Excel».

- الأعمدة المقبولة بالعربية أو الإنجليزية: رقم القطعة، الاسم، الفئة، العلامة،
  الرقم الأصلي، الجودة (أصلي/تجاري/مستعمل)، أسماء أخرى، الباركود، سعر الشراء،
  سعر البيع، الكمية، حد التنبيه، الرف، الوصف.
- يُعرض أولاً **معاينة** بالأخطاء لكل صف؛ لا يُحفظ شيء حتى تصحّح كل الأخطاء
  وتضغط «تطبيق».
- القطع الجديدة تدخل برصيدها كحركة «رصيد افتتاحي».
- القطع الموجودة (نفس رقم القطعة) تُحدَّث بياناتها وسعر بيعها فقط إن اخترت
  ذلك؛ **الكمية والتكلفة لا تتغيران من الملف** — صحّح الكمية بالجرد.
- الفئات غير الموجودة تُنشأ تلقائياً.
- تظهر في المعاينة أخطاء الصفوف التالية: رقم قطعة أو باركود مكرر داخل الملف،
  وخلية غير رقمية (مثل `#N/A`)، وكمية أو سعر أكبر من المعقول، ونص أطول من
  الحقل.

**الأسماء الدارجة** مهمة: اكتب في «أسماء أخرى» ما يقوله الزبائن والموظفون
(مثل: طرمبة، رديتر، بوجي)، فيجدها البحث بأي تسمية.

## 4. البيع والدفع

- **نقدي / تحويل / مختلط / آجل** من شاشة نقطة البيع.
- **التحويل:** اختر الحساب البنكي، واكتب رقم الإشعار ورقم حساب المرسل، وأرفق
  صورة الإشعار إن وُجدت. **رقم الإشعار لا يُقبل مرتين** في النظام كله (حتى
  مع اختلاف المسافات والشرطات) — هذا يمنع إعادة استخدام صورة إشعار قديمة.
- **الآجل:** للعميل الذي حدد له المدير «حد ائتمان» فقط، ولا يتجاوز الحد.
  يمكن دفع جزء والباقي آجل.
- **خصم الورش والجملة:** يُضبط من الإعدادات، ويُطبّق تلقائياً على عملاء هذا
  النوع (أو خصم خاص لعميل معيّن).
- **قارئ الباركود:** امسح في خانة البحث فتُضاف القطعة مباشرة. إن طابق الرمز
  أكثر من قطعة (رقم أصلي مشترك بين الأصلي والتجاري مثلاً) لا يُضاف شيء، وتظهر
  القطع المطابقة لتختار منها. وكذلك في الجرد: لا يُعدّ المسح حتى تختار القطعة.
- **الإيصال:** يُطبع بعد البيع على طابعة حرارية 80 أو 58 مم أو A4 (من
  الإعدادات: هوية المحل، الهاتف، العنوان، الرقم الضريبي إن وُجد، التذييل).

## 5. الديون والتحصيل

- صفحة **العملاء** ← «المدينون» تعرض من عليهم مبالغ.
- صفحة العميل: الرصيد، **كشف الحساب** بالرصيد الجاري (قابل للطباعة)، و
  **تسجيل دفعة** نقداً أو تحويلاً.

## 6. المرتجعات

من **الفواتير** ← الفاتورة ← «مرتجع» (للمدير والمشرف):

- اختر الكميات المرتجعة (لا تتجاوز المباع ناقص ما أُرجع سابقاً).
- الكمية تعود للمخزون بتكلفتها الأصلية.
- ردّ المبلغ: نقداً أو تحويلاً (بما لا يتجاوز ما دُفع فعلاً)، أو خصماً من
  حساب العميل الآجل.
- التقارير تحسب الإيراد والربح **صافيين** من المرتجعات.

## 7. إقفال اليومية ومطابقة التحويلات

**إقفال اليومية** (نهاية كل يوم):

1. سجّل المصروفات (إيجار، كهرباء، ترحيل...).
2. اعدّ النقد في الدرج وأدخله؛ النظام يعرض النقد المتوقع والفرق (عجز/زيادة).
3. أقفل اليوم. بعدها لا تُضاف مصروفات لذلك اليوم، ويبدأ اليوم التالي بنقد
   الدرج المعدود.

**مطابقة التحويلات:** قارن كل تحويل بكشف الحساب (مثل بنكك) ثم اضغط «مطابقة».
التحويلات غير المطابقة تظهر في ملخص اليوم.

## 8. الجرد

صفحة **الجرد** ← «جرد جديد»، ثم امسح كل قطعة (كل مسح = +1) بقارئ الباركود أو
بكاميرا الهاتف (متصفح كروم على أندرويد)، أو ابحث وأدخل العدد. عند «تطبيق»
يصبح رصيد كل قطعة معدودة مساوياً للعدد الفعلي، بحركة «جرد» للفرق. القطع غير
المعدودة لا تتغير.

**ملصقات الباركود:** من **قطع الغيار** حدّد القطع ← «طباعة ملصقات» (برقم القطعة
إن لم يكن لها باركود).

## 9. التسعير بسعر الصرف

لكل قطعة مستوردة: عملة الشراء (دولار، درهم، ريال...) وتكلفتها بتلك العملة.
التوريد بعملة أجنبية يحدّثها تلقائياً.

عند تغيّر السعر: **الإعدادات** ← «أسعار الصرف» ← سجّل السعر الجديد ←
«مراجعة الأسعار» (معاينة القديم والجديد) ← «تطبيق». يمكن اختيار «عدم خفض أي
سعر».

سعر البيع = التكلفة الأجنبية × سعر الصرف × (1 + هامش الربح)، مقرّباً لأعلى
حسب إعداد التقريب. الهامش: للقطعة إن حُدد، وإلا للفئة، وإلا الهامش العام.
